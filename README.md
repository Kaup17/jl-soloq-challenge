# JL SoloQ Challenge

Tracker Next.js pour Wati, Kada, KobeADC et FakeMonster.

## Lancer
1. Installer Node.js 20.9+
2. `npm install`
3. copier `.env.example` vers `.env.local`
4. `npm run dev`
5. ouvrir http://localhost:3000
